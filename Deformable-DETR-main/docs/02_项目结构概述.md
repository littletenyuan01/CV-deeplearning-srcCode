## 二、执行流程

### 2.1 训练流程

```
main.py  (入口)
  ├── 解析命令行参数 (get_args_parser)
  ├── 构建数据集 (build_dataset)
  ├── 构建模型 (build_model)
  │     ├── build_backbone()          → ResNet-50
  │     ├── build_deforamble_transformer()  → DeformableTransformer
  │     └── DeformableDETR(backbone, transformer, ...)
  ├── 构建损失函数 SetCriterion + HungarianMatcher
  ├── 构建优化器 (AdamW)
  └── 训练循环
        └── engine.py::train_one_epoch()
              ├── model(samples)        → forward pass
              ├── criterion(outputs, targets)  → 计算损失
              ├── loss.backward()       → 反向传播
              └── optimizer.step()      → 参数更新
```

### 2.2 前向推理流程

```
图像输入 [B, 3, H, W]
  │
  ├── Backbone (ResNet)
  │     └── 输出多尺度特征图 {C3, C4, C5} + 额外 C6
  │         C3: [B, 512, H/8, W/8]
  │         C4: [B, 1024, H/16, W/16]
  │         C5: [B, 2048, H/32, W/32]
  │         C6: [B, 256, H/64, W/64]  (通过 stride=2 卷积从 C5 生成)
  │
  ├── input_proj (1×1 Conv + GroupNorm)
  │     └── 各层通道映射到 hidden_dim=256
  │
  ├── Position Embedding (正弦编码)
  │     └── 对每层特征计算位置编码, 加上 level_embed
  │
  ├── DeformableTransformer
  │     ├── Encoder (×6)
  │     │     ├── MSDeformAttn (可变形自注意力)
  │     │     └── FFN
  │     └── Decoder (×6)
  │           ├── MultiheadAttn (标准自注意力, query 间交互)
  │           ├── MSDeformAttn (可变形交叉注意力, query↔encoder)
  │           └── FFN
  │
  ├── class_embed (Linear: 256 → num_classes)
  │     └── 预测类别 logits
  │
  └── bbox_embed (MLP: 256 → 256 → 4)
        └── 预测边界框 (cx, cy, w, h) ∈ [0,1]
```

## 三、关键配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--backbone` | `resnet50` | Backbone 网络 |
| `--hidden_dim` | `256` | Transformer 隐层维度 |
| `--nheads` | `8` | 注意力头数 |
| `--enc_layers` | `6` | Encoder 层数 |
| `--dec_layers` | `6` | Decoder 层数 |
| `--dim_feedforward` | `1024` | FFN 中间层维度 |
| `--num_queries` | `300` | Object queries 数量 |
| `--num_feature_levels` | `4` | 多尺度特征层级数 |
| `--dec_n_points` | `4` | Decoder 每层采样点数 |
| `--enc_n_points` | `4` | Encoder 每层采样点数 |
| `--dropout` | `0.1` | Dropout 比率 |
| `--epochs` | `50` | 训练轮数 |
| `--lr` | `2e-4` | 学习率（Transformer 部分） |
| `--lr_backbone` | `2e-5` | 学习率（Backbone 部分） |
| `--batch_size` | `2` | 每 GPU 的 batch size |
| `--with_box_refine` | `False` | 是否启用迭代边界框精调 |
| `--two_stage` | `False` | 是否启用两阶段模式 |
