## 一、DeformableDETR（主模型）

**文件**：`models/deformable_detr.py`

### 1.1 类结构

```python
class DeformableDETR(nn.Module):
    def __init__(self, backbone, transformer, num_classes,
                 num_queries, num_feature_levels,
                 aux_loss=True, with_box_refine=False, two_stage=False):
```

### 1.2 关键组件

| 组件 | 类型 | 说明 |
|------|------|------|
| `backbone` | `Backbone` | ResNet-50/101，输出多尺度特征图 |
| `transformer` | `DeformableTransformer` | 可变形 Transformer |
| `query_embed` | `nn.Embedding(300, 512)` | 可学习的 object queries（非两阶段模式） |
| `class_embed` | `nn.Linear(256, num_classes)` | 分类头 |
| `bbox_embed` | `MLP(256, 256, 4, 3)` | 边界框回归头 |
| `input_proj` | `ModuleList[Conv1x1+GN]` | 多尺度特征投影层 |

### 1.3 前向传播流程

1. **Backbone 提取特征**：`features, pos = self.backbone(samples)`
2. **多尺度投影**：各层特征通过 1×1 Conv + GroupNorm 映射到 `hidden_dim`
3. **额外特征层生成**：如果 `num_feature_levels > len(srcs)`，用 stride=2 的 3×3 卷积生成更小尺度的特征图
4. **Transformer 处理**：`hs, init_reference, inter_references = self.transformer(...)`
5. **预测头**：每个 decoder 层的输出分别经过 `class_embed` 和 `bbox_embed`
6. **边界框解码**：`bbox = sigmoid(bbox_embed(hs) + inverse_sigmoid(reference))`

### 1.4 两阶段模式

```python
if self.two_stage:
    # encoder 输出直接用于生成 proposals
    # 选出 top-300 分数最高的作为 decoder 的初始 object queries
    enc_outputs_class = self.decoder.class_embed[decoder.num_layers](output_memory)
    enc_outputs_coord = self.decoder.bbox_embed[decoder.num_layers](output_memory) + output_proposals
    topk = torch.topk(enc_outputs_class[..., 0], 300, dim=1)[1]
    # topk_coords 作为 decoder 的 reference_points
```

## 二、DeformableTransformer

**文件**：`models/deformable_transformer.py`

### 2.1 整体结构

```python
class DeformableTransformer(nn.Module):
    def __init__(self, d_model=256, nhead=8,
                 num_encoder_layers=6, num_decoder_layers=6,
                 num_feature_levels=4, dec_n_points=4, enc_n_points=4,
                 two_stage=False, two_stage_num_proposals=300):
```

### 2.2 Encoder 层

```python
class DeformableTransformerEncoderLayer(nn.Module):
    # self_attn: MSDeformAttn(d_model, n_levels, n_heads, n_points)
    # FFN: Linear(d_model, d_ffn) → ReLU → Dropout → Linear(d_ffn, d_model)

    def forward(self, src, pos, reference_points, spatial_shapes,
                level_start_index, padding_mask):
        # 1. 可变形自注意力
        src2 = self.self_attn(src + pos, reference_points, src,
                              spatial_shapes, level_start_index, padding_mask)
        src = src + dropout(src2)    # 残差连接
        src = norm(src)              # LayerNorm

        # 2. FFN
        src = self.forward_ffn(src)  # 残差 + LN
        return src
```

**Encoder 参考点生成**：

每个像素的归一化坐标作为参考点：
```python
def get_reference_points(spatial_shapes, valid_ratios, device):
    for lvl, (H_, W_) in enumerate(spatial_shapes):
        ref_y, ref_x = torch.meshgrid(...)
        # 归一化到 [0, 1]，考虑 padding 的有效区域
        ref_y = ref_y / (valid_ratios[:, lvl, 1] * H_)
        ref_x = ref_x / (valid_ratios[:, lvl, 0] * W_)
```

### 2.3 Decoder 层

```python
class DeformableTransformerDecoderLayer(nn.Module):
    # self_attn:  nn.MultiheadAttention (标准注意力)
    # cross_attn: MSDeformAttn (可变形交叉注意力)
    # FFN: 标准前馈网络

    def forward(self, tgt, query_pos, reference_points, src,
                src_spatial_shapes, level_start_index, src_padding_mask):
        # 1. 标准自注意力（query 之间交互）
        tgt2 = self.self_attn(tgt + query_pos, tgt + query_pos, tgt)
        tgt = tgt + dropout(tgt2)   # 残差
        tgt = norm(tgt)             # LayerNorm

        # 2. 可变形交叉注意力（query 关注 encoder 输出）
        tgt2 = self.cross_attn(tgt + query_pos, reference_points,
                               src, src_spatial_shapes,
                               level_start_index, src_padding_mask)
        tgt = tgt + dropout(tgt2)   # 残差
        tgt = norm(tgt)             # LayerNorm

        # 3. FFN
        tgt = self.forward_ffn(tgt)
        return tgt
```

**关键区别**：
- Encoder 中自注意力和交叉注意力合并为可变形注意力（因为 query=key=特征图本身）
- Decoder 中自注意力保持标准全局注意力（让 queries 之间互相感知），交叉注意力使用可变形版本

## 三、MSDeformAttn（多尺度可变形注意力）

**文件**：`models/ops/modules/ms_deform_attn.py`

### 3.1 模块定义

```python
class MSDeformAttn(nn.Module):
    def __init__(self, d_model=256, n_levels=4, n_heads=8, n_points=4):
        # 线性层：预测采样偏移 (n_heads × n_levels × n_points × 2)
        self.sampling_offsets = nn.Linear(d_model, n_heads * n_levels * n_points * 2)

        # 线性层：预测注意力权重 (n_heads × n_levels × n_points)
        self.attention_weights = nn.Linear(d_model, n_heads * n_levels * n_points)

        # Value 投影和输出投影
        self.value_proj = nn.Linear(d_model, d_model)
        self.output_proj = nn.Linear(d_model, d_model)
```

### 3.2 参数初始化技巧

采样偏移的 bias 初始化为**网格状分布**，不同 head 面朝不同方向：

```python
thetas = torch.arange(n_heads) * (2.0 * pi / n_heads)
grid_init = torch.stack([thetas.cos(), thetas.sin()], -1)
# head 0 朝 0°, head 1 朝 45°, head 2 朝 90°, ...

for i in range(n_points):
    grid_init[:, :, i, :] *= i + 1
# 第 i 个采样点偏移量为 (i+1) 倍
# 即采样点 0 近, 采样点 1 稍远, ..., 形成多尺度感受野
```

### 3.3 前向传播

```python
def forward(self, query, reference_points, input_flatten,
            input_spatial_shapes, input_level_start_index,
            input_padding_mask=None):
    # 1. 计算 value
    value = self.value_proj(input_flatten)  # [N, ΣHlWl, C]

    # 2. 预测采样偏移和注意力权重
    sampling_offsets = self.sampling_offsets(query)
    # shape: [N, Len_q, n_heads, n_levels, n_points, 2]
    attention_weights = softmax(self.attention_weights(query))
    # shape: [N, Len_q, n_heads, n_levels * n_points]

    # 3. 调用 CUDA 实现的 MSDeformAttnFunction
    output = MSDeformAttnFunction.apply(
        value, input_spatial_shapes, input_level_start_index,
        sampling_offsets, attention_weights, self.im2col_step)

    # 4. 输出投影
    return self.output_proj(output)
```

### 3.4 CUDA 实现

CUDA 核心实现在 `models/ops/src/cuda/ms_deform_attn_cuda.cu`：

```cuda
// 关键步骤：
// 1. 根据 sampling_offsets + reference_points 计算实际采样位置
// 2. 对每个采样位置进行双线性插值
// 3. 乘以注意力权重并求和
```

### 4.3 FrozenBatchNorm2d

训练时固定 BatchNorm 的统计量和参数，保持预训练权重不变：

```python
class FrozenBatchNorm2d(nn.Module):
    # running_mean, running_var, weight, bias 均为固定值
    def forward(self, x):
        scale = weight * (running_var + eps).rsqrt()
        bias = bias - running_mean * scale
        return x * scale + bias
```

## 六、HungarianMatcher（匈牙利匹配器）

**文件**：`models/matcher.py`

### 6.1 匹配代价

```python
# 代价矩阵 = C_class + C_bbox + C_giou
C_class = -(α*(1-p)^γ*log(p) + (1-α)*p^γ*log(1-p))  # Focal Loss 形式的代价
C_bbox  = L1(pred_bbox, tgt_bbox)                      # L1 距离
C_giou  = -GIoU(pred_bbox, tgt_bbox)                   # GIoU (取负)
Total_C = cost_class*C_class + cost_bbox*C_bbox + cost_giou*C_giou
```

### 6.2 匹配过程

```python
from scipy.optimize import linear_sum_assignment

# 对每个 batch 元素
for b in range(batch_size):
    indices = linear_sum_assignment(cost_matrix[b])
    # indices: (pred_indices, tgt_indices)
```

- 每个真值框恰好匹配一个预测框
- 多余的预测框自动成为 "no object"
- 使用 Focal Loss 形式的代价而非交叉熵（更好地处理类别不平衡）

## 七、位置编码

**文件**：`models/position_encoding.py`

### 7.1 正弦位置编码

```python
class PositionEmbeddingSine(nn.Module):
    def forward(self, tensor_list):
        # 1. 生成 y_embed, x_embed（归一化的空间坐标）
        y_embed = not_mask.cumsum(1) / (max_y + eps) * 2π
        x_embed = not_mask.cumsum(2) / (max_x + eps) * 2π

        # 2. 频率编码
        dim_t = 10000^(2i/d)   # i=0..num_pos_feats-1
        pos_x = sin/cos(x_embed / dim_t)
        pos_y = sin/cos(y_embed / dim_t)

        # 3. 拼接：[C, H, W]
        return cat(pos_y, pos_x)
```
