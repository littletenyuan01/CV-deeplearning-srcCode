## 一、前置知识：DETR 详解与局限性

### 1.1 DETR 架构回顾

DETR（DEtection TRansformer）是 Facebook AI 于 2020 年提出的首个将 Transformer 应用于端到端目标检测的框架。其核心思想是**将目标检测视为集合预测问题**，彻底消除了 NMS（非极大值抑制）、Anchor（锚框）等传统检测器中的手工设计组件。

### 1.2 DETR 的 Transformer 注意力机制

DETR 使用标准的多头自注意力（Multi-Head Self-Attention），其核心公式为：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

展开为多头形式：

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

在 DETR 中：
- **Encoder 自注意力**：Q=K=V=图像特征图（flatten 为序列），每个像素关注所有其他像素
- **Decoder 自注意力**：Q=K=V=object queries，queries 之间相互交互
- **Decoder 交叉注意力**：Q=object queries，K=V=Encoder 输出特征图

### 1.3 DETR 的问题一：收敛极慢

DETR 需要训练 **500 epoch** 才能收敛，而 Faster R-CNN 仅需 12～25 epoch。根源在于**交叉注意力模块**的初始化问题：

```
训练初期的交叉注意力权重分布（示意）：

Query 1 ● ────────────────────────────── 均匀分布 ──────────────────────────────
         0.001  0.001  0.001  0.001  ...  0.001  0.001  0.001  0.001
         □□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□□
         位置 0   1    2    3   ...   HW-3  HW-2  HW-1

问题：所有位置的注意力权重几乎相等，模型需要大量迭代才能学会"聚焦"
```

**数学解释**：初始时，Query 和 Key 的投影矩阵是随机初始化的，因此 $QK^T$ 近似均匀分布。softmax 后的结果也近似均匀，导致每个 query 对所有 key 位置给出几乎相同的注意力。模型必须通过大量训练才能学习到有意义的稀疏注意力模式。

### 1.4 DETR 的问题二：计算复杂度高

标准 Transformer 注意力的计算复杂度：

$$O(\text{Attention}) = O(N_q \cdot N_k \cdot d) = O(H_qW_q \cdot H_kW_k \cdot d)$$

具体来说：
- **Encoder**：$O(HW \cdot HW \cdot C)$ — 空间分辨率的**平方级**复杂度
- 即使对 800×800 的输入图像，特征图约为 25×25=625 个 token
- 自注意力矩阵大小为 625×625，对高分辨率特征图（如 100×100=10000）代价不可接受

这意味着 DETR **只能使用低分辨率的特征图**（ResNet C5 层，stride=32），无法使用高分辨率的浅层特征（如 C3，stride=8），导致对小目标的检测能力严重不足。

## 二、核心创新：可变形注意力机制

### 2.1 核心直觉

> **关键洞察**：对于目标检测而言，每个 query 只需要关注特征图中的少数关键位置，而不是全部位置。

类比人类的视觉注意力——当我们在一张图中寻找物体时，眼睛会快速聚焦到少数几个关键区域，而不是均匀地扫描整张图的每个像素。

```
可变形注意力的直觉（对比标准注意力）：

┌─── 标准注意力 ──────────────────────┐  ┌─── 可变形注意力 ───────────────────┐
│                                     │  │                                   │
│  Query●关注所有位置                  │  │  Query●只关注参考点附近的K个位置    │
│                                     │  │                                   │
│  ┌─────────────────────────┐        │  │            特征图                  │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  ┌─────────────────────────┐      │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  │                         │      │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  │       p_q(参考点)       │      │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  │         ●              │      │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  │      ◆  ◆  ◆          │      │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  │        ◆               │      │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  │                         │      │
│  │ □ □ □ □ □ □ □ □ □ □    │        │  │  │  ◆ = 采样点(K=4)       │      │
│  └─────────────────────────┘        │  │  └─────────────────────────┘      │
│  关注 100 个位置                     │  │  仅关注 4 个位置                  │
│  复杂度: O(HW)                       │  │  复杂度: O(K)                    │
└─────────────────────────────────────┘  └───────────────────────────────────┘
```

灵感直接来源于**可变形卷积**（Deformable Convolution, Dai et al., ICCV 2017），它让卷积核的采样位置不再是固定的网格，而是可以通过学习偏移量来变形。

### 2.2 可变形注意力——单尺度版本

#### 2.2.1 数学公式

标准多头注意力：

$$\text{MultiHeadAttn}(z_q, x) = \sum_{m=1}^{M} W_m \left[ \sum_{k \in \Omega_k} A_{mqk} \cdot W'_m x_k \right]$$

可变形注意力替换求和范围为稀疏采样点：

$$\text{DeformAttn}(z_q, p_q, x) = \sum_{m=1}^{M} W_m \left[ \sum_{k=1}^{K} A_{mqk} \cdot W'_m x(p_q + \Delta p_{mqk}) \right]$$

#### 2.2.2 符号说明

| 符号 | 维度 | 含义 | 计算方式 |
|------|------|------|----------|
| \(z_q \in \mathbb{R}^C\) | [C] | 第 q 个 query 的特征向量 | 来自上一层输出 |
| \(p_q \in [0,1]^2\) | [2] | 参考点（归一化坐标） | decoder：由 query 经 Linear 预测；encoder：像素自身坐标 |
| \(\Delta p_{mqk} \in \mathbb{R}^2\) | [2] | 第 m 个头、第 k 个采样点的偏移量 | 由 query 经 Linear 层预测，无范围限制 |
| \(A_{mqk} \in [0,1]\) | 标量 | 第 m 个头、第 k 个采样点的注意力权重 | 由 query 经 Linear + softmax 得到 |
| \(M\) | — | 注意力头数 | 超参数（默认 8） |
| \(K\) | — | 每个头的采样点数 | 超参数（默认 4，K ≪ HW） |
| \(W_m, W'_m\) | [d_v, C], [d_v, C] | 第 m 个头的投影矩阵 | 可学习参数 |

#### 2.2.3 采样偏移 Δp 和注意力权重 A 的产生过程

```
 query z_q [C]
     │
     ├──▶ Linear(C, 2×M×K) ──▶ reshape ──▶ Δp_{mqk} ∈ R²   (采样偏移)
     │
     └──▶ Linear(C, M×K)  ──▶ softmax  ──▶ A_{mqk}  ∈ [0,1] (注意力权重)
                                              Σ_k A_{mqk} = 1
```

具体代码对应（[ms_deform_attn.py](file:///D:/computerLearn/cvLearning/6.%E7%AC%AC%E5%85%AD%E7%AB%A0%20%E7%BB%BC%E5%90%88%E9%A0%B9%EF%A3%B1-%E7%89%A9%E4%BD%93%E6%A3%80%E6%B5%8B%E7%BB%8F%E5%85%B8%E7%AE%97%E6%B3%95%E5%AE%9E%E6%88%98/Deformable-DETR-main/Deformable-DETR-main/models/ops/modules/ms_deform_attn.py)）：

```python
# 预测采样偏移: [Len_q, C] → [Len_q, n_heads * n_levels * n_points * 2]
self.sampling_offsets = nn.Linear(d_model, n_heads * n_levels * n_points * 2)

# 预测注意力权重: [Len_q, C] → [Len_q, n_heads * n_levels * n_points]
self.attention_weights = nn.Linear(d_model, n_heads * n_levels * n_points)
# 注意：attention_weights 出来后要过 softmax 归一化
```

#### 2.2.4 双线性插值采样

由于 \(\Delta p\) 是连续值，\(p_q + \Delta p_{mqk}\) 几乎不落在整数坐标上，需用**双线性插值**从离散特征图上取值：

$$x(p) = \sum_{g \in \mathcal{G}(p)} x(g) \cdot \max(0, 1 - |p_x - g_x|) \cdot \max(0, 1 - |p_y - g_y|)$$

其中 \(\mathcal{G}(p) = \{\lfloor p_x \rfloor, \lceil p_x \rceil\} \times \{\lfloor p_y \rfloor, \lceil p_y \rceil\}\) 是 p 周围的 4 个整数网格点。

```
双线性插值示意图：

        g_tl=(⌊px⌋, ⌊py⌋)          g_tr=(⌈px⌉, ⌊py⌋)
              ● ───────────────────── ●
              │\                      │\
              │ \                     │ \
              │  \                    │  \
              │   \                   │   \
              │    ● p=(px, py)       │    \
              │                       │
              ● ───────────────────── ●
        g_bl=(⌊px⌋, ⌈py⌉)          g_br=(⌈px⌉, ⌈py⌉)

插值权重：
  w_tl = (1 - |px - ⌊px⌋|) × (1 - |py - ⌊py⌋|)
  w_tr = |px - ⌊px⌋|         × (1 - |py - ⌊py⌋|)
  w_bl = (1 - |px - ⌊px⌋|) × |py - ⌊py⌋|
  w_br = |px - ⌊px⌋|        × |py - ⌊py⌋|

结果：x(p) = w_tl·x(g_tl) + w_tr·x(g_tr) + w_bl·x(g_bl) + w_br·x(g_br)
```

这个操作在 CUDA kernel 中高效实现（[ms_deform_attn_cuda.cu](file:///D:/computerLearn/cvLearning/6.%E7%AC%AC%E5%85%AD%E7%AB%A0%20%E7%BB%BC%E5%90%88%E9%A0%B9%EF%A3%B1-%E7%89%A9%E4%BD%93%E6%A3%80%E6%B5%8B%E7%BB%8F%E5%85%B8%E7%AE%97%E6%B3%95%E5%AE%9E%E6%88%98/Deformable-DETR-main/Deformable-DETR-main/models/ops/src/cuda/ms_deform_attn_cuda.cu)）。

### 2.3 多尺度可变形注意力（MSDeformAttn）——核心版本

这是 Deformable DETR 实际使用的版本，能同时处理 L 层特征图。

#### 2.3.1 数学公式

$$\text{MSDeformAttn}(z_q, \hat{p}_q, \{x^l\}_{l=1}^{L}) = \sum_{m=1}^{M} W_m \left[ \sum_{l=1}^{L} \sum_{k=1}^{K} A_{mlqk} \cdot W'_m x^l(\phi_l(\hat{p}_q) + \Delta p_{mlqk}) \right]$$

#### 2.3.2 新增符号

| 符号 | 含义 |
|------|------|
| \(L\) | 多尺度特征图层数（默认 4：C3, C4, C5, C6） |
| \(x^l\) | 第 l 层特征图，尺寸为 \(H_l \times W_l\) |
| \(\phi_l(\hat{p}_q)\) | 将归一化坐标 \(\hat{p}_q\) 映射到第 l 层的实际像素坐标：\(\phi_l(\hat{p}_q) = \hat{p}_q \cdot (W_l, H_l)\) |
| \(A_{mlqk}\) | 第 m 个头、第 l 层、第 k 个采样点的注意力权重 |

#### 2.3.3 多尺度采样的直观理解

```
多尺度特征图上的可变形采样：

Layer 0 (C3, stride=8, 高分辨率)          Layer 1 (C4, stride=16)
┌────────────────────────────────┐       ┌────────────────────┐
│                                │       │                    │
│      ◆                         │       │     ◆              │
│   ◆     ◆                      │       │  ◆     ◆   ●p_q    │
│        ●p_q                    │       │                    │
│                                │       │                    │
└────────────────────────────────┘       └────────────────────┘

Layer 2 (C5, stride=32)                  Layer 3 (C6, stride=64, 低分辨率)
┌────────────────────┐                   ┌──────────────┐
│                    │                   │              │
│   ◆      ◆        │                   │     ◆  ◆     │
│        ●p_q       │                   │      ●p_q    │
│     ◆             │                   │              │
└────────────────────┘                   └──────────────┘

● = 参考点 p_q（在所有层对应同一位置）
◆ = 采样点（每层采样偏移不同，模型自适应选择最佳尺度的信息）
```

小目标倾向于在高分辨率层（C3）分配更高注意力，大目标倾向于在低分辨率层（C5/C6）分配更高注意力。

### 2.4 复杂度对比

```
计算复杂度比较：

                         DETR                          Deformable DETR
                         ────                          ───────────────
Encoder 自注意力:   O(HW × HW × C)              O(HW × K × C)  = O(HW × 4 × C)
                    ≈ O(H²W²C)                   ≈ O(4·HW·C)

Decoder 交叉注意力: O(N_q × HW × C)              O(N_q × L × K × C) = O(N_q × 16 × C)
                    ≈ O(300·HW·C)                ≈ O(4800·C)

具体数值（以 800×800 输入为例）：
  HW ≈ 625 (C5)                               HW ≈ 625 + 2500 + 10000 + ... 但每层只采样 4 个点！
  Encoder: 625² = 390,625 次交互              Encoder: 625 × 4 = 2,500 次交互（减少 156×）
  Decoder: 300 × 625 = 187,500 次交互          Decoder: 300 × 4 × 4 = 4,800 次交互（减少 39×）
```

### 2.5 采样偏移 Δp 的初始化策略

这是一个重要的实现细节。如果 Δp 初始化为全 0，所有采样点都会坍缩到参考点本身，失去空间多样性。论文采用了一个巧妙的**网格状初始化**：

```
采样偏移初始化（以 n_heads=8, n_points=4 为例）：

Head 0:  → 方向 0°     Head 1:  ↗ 方向 45°    Head 2:  ↑ 方向 90°    Head 3:  ↖ 方向 135°
          ◆                             ◆                        ◆                       ◆
          ◆◆◆                          ◆◆◆                     ◆◆◆                    ◆◆◆
       ●  ◆                        ●  ◆                   ●  ◆  ◆                 ●  ◆
          ◆                            ◆                        ◆                       ◆
          ◆                             ◆                        ◆                       ◆

Head 4:  ← 方向 180°    Head 5:  ↙ 方向 225°   Head 6:  ↓ 方向 270°   Head 7:  ↘ 方向 315°

采样点 0 最近（偏移量×1），采样点 3 最远（偏移量×4）→ 自然形成多尺度感受野
```

代码实现（[ms_deform_attn.py](file:///D:/computerLearn/cvLearning/6.%E7%AC%AC%E5%85%AD%E7%AB%A0%20%E7%BB%BC%E5%90%88%E9%A0%B9%EF%A3%B1-%E7%89%A9%E4%BD%93%E6%A3%80%E6%B5%8B%E7%BB%8F%E5%85%B8%E7%AE%97%E6%B3%95%E5%AE%9E%E6%88%98/Deformable-DETR-main/Deformable-DETR-main/models/ops/modules/ms_deform_attn.py)）：

```python
def _reset_parameters(self):
    # 将 sampling_offsets 的 weight 初始化为 0（bias 负责初始化方向）
    constant_(self.sampling_offsets.weight.data, 0.)

    # 每个 head 分配一个均匀分布的方向角
    thetas = torch.arange(self.n_heads, dtype=torch.float32) * (2.0 * math.pi / self.n_heads)
    grid_init = torch.stack([thetas.cos(), thetas.sin()], -1)
    # grid_init shape: [n_heads, 2]，每个 head 指向不同方向

    # 归一化，保证偏移量在不同方向上可比较
    grid_init = grid_init / grid_init.abs().max(-1, keepdim=True)[0]

    # 扩展到 [n_heads, n_levels, n_points, 2]
    grid_init = grid_init.view(n_heads, 1, 1, 2).repeat(1, n_levels, n_points, 1)

    # 第 i 个采样点偏移 i+1 倍 → 越远的采样点偏移越大
    for i in range(self.n_points):
        grid_init[:, :, i, :] *= i + 1

    self.sampling_offsets.bias = nn.Parameter(grid_init.view(-1))

    # attention_weights 初始化为 0 → softmax 后均匀分布（各采样点权重相等）
    constant_(self.attention_weights.weight.data, 0.)
    constant_(self.attention_weights.bias.data, 0.)
```

### 4.2 Encoder 参考点生成

每个像素使用**自己本身的归一化坐标**作为参考点（因为自注意力中 query 就是特征本身）：

```python
def get_reference_points(spatial_shapes, valid_ratios, device):
    """为每个特征图上的每个像素生成归一化参考点"""
    reference_points_list = []
    for lvl, (H_, W_) in enumerate(spatial_shapes):
        # 生成网格坐标，从 (0.5, 0.5) 到 (H_-0.5, W_-0.5)
        ref_y, ref_x = torch.meshgrid(
            torch.linspace(0.5, H_ - 0.5, H_, device=device),
            torch.linspace(0.5, W_ - 0.5, W_, device=device)
        )
        # 归一化到 [0, 1]，考虑 valid_ratios（padding 不影响归一化）
        ref_y = ref_y.reshape(-1)[None] / (valid_ratios[:, None, lvl, 1] * H_)
        ref_x = ref_x.reshape(-1)[None] / (valid_ratios[:, None, lvl, 0] * W_)
        ref = torch.stack((ref_x, ref_y), -1)
        reference_points_list.append(ref)
    reference_points = torch.cat(reference_points_list, 1)  # [B, ΣHlWl, 2]
    # 再乘以 valid_ratios 以考虑 padding 区域
    reference_points = reference_points[:, :, None] * valid_ratios[:, None]
    return reference_points  # [B, ΣHlWl, L, 2]
```

### 4.3 为什么 Encoder 也用可变形注意力？

- DETR encoder 使用标准全局自注意力，复杂度 \(O((HW)^2)\)
- Deformable DETR encoder 使用可变形自注意力，复杂度 \(O(HW \cdot K)\)
- 核心假设：对于特征图上的每个像素，只需要关注其**空间邻域**内的少数点即可完成特征增强，不需要全局交互
- 全局语义信息可以通过堆叠多层 encoder + 多尺度特征图来间接获得

### 5.2 为什么 Decoder 自注意力保持标准版？

这是一个关键设计决策：

| 注意力类型 | Encoder | Decoder |
|-----------|---------|---------|
| 自注意力 | 可变形版本 | **标准全局版本** |
| 交叉注意力 | N/A（自注意力即交叉） | 可变形版本 |

原因：
1. **queries 数量少**（300 个），标准自注意力复杂度 \(O(300^2)\) 完全可接受
2. **queries 之间需要全局交互**——每个 query 需要知道其他 query 关注了哪里，才能避免重复检测
3. 可变形自注意力用于 query 之间没有意义——queries 本身没有空间位置概念

## 六、两个改进变体

### 6.1 迭代边界框精调（Iterative Bounding Box Refinement）

#### 6.1.1 动机

标准 DETR/Deformable DETR 中，每个 decoder 层独立预测边界框。迭代精调将**前一层的预测作为下一层的输入**，形成由粗到精的级联优化。

#### 6.1.2 数学描述

```
Standard Deformable DETR  Decoder:         Iterative Refinement Decoder:
─────────────────────────────────         ─────────────────────────────

Layer 1:                                   Layer 1:
  ref₁ = sigmoid(Linear(query_embed))        ref₁ = sigmoid(Linear(query_embed))
  tgt₁ = Decoder(tgt₀, ref₁, memory)         tgt₁ = Decoder(tgt₀, ref₁, memory)
  bbox₁ = sigmoid(bbox_embed(tgt₁))          Δbbox₁ = bbox_embed₁(tgt₁)
                                             bbox₁ = sigmoid(inv_sigmoid(ref₁) + Δbbox₁)

Layer 2:                                   Layer 2:
  ref₂ = sigmoid(Linear(query_embed))  ✗     ref₂ = bbox₁  ← 使用上一层的预测！
  tgt₂ = Decoder(tgt₁, ref₂, memory)         tgt₂ = Decoder(tgt₁, ref₂, memory)
  bbox₂ = sigmoid(bbox_embed(tgt₂))          Δbbox₂ = bbox_embed₂(tgt₂)
                                             bbox₂ = sigmoid(inv_sigmoid(ref₂) + Δbbox₂)

...同样 pattern...                          ...同样 pattern...

问题: 每层参考点一样, 各层独立预测      优势: 每层预测残差, 逐步精调
```

核心公式：

$$b^{(l)} = \sigma\left( \sigma^{-1}(b^{(l-1)}) + \text{MLP}^{(l)}(h^{(l)}) \right)$$

其中：
- \(b^{(l)}\) 是第 \(l\) 层的边界框预测
- \(\sigma\) 是 sigmoid（将值映射到 [0,1]）
- \(\sigma^{-1}\) 是 inverse sigmoid（logit 函数）
- \(\text{MLP}^{(l)}\) 是第 \(l\) 层专用的 bbox_embed
- \(h^{(l)}\) 是 decoder 第 \(l\) 层的输出 hidden state

#### 6.1.3 为什么在 logit 空间做残差？

```
在 logit 空间 (inverse_sigmoid) 做加法，在 sigmoid 空间体现为"乘性"修正：

  new_ref = sigmoid(inv_sigmoid(old_ref) + delta)

这样做的优势：
  - old_ref 接近 0 或 1 时，delta 的影响自动变小（sigmoid 饱和区梯度小）
  - 避免了 sigmoid 空间中直接加法的数值不稳定
```

### 6.2 两阶段 Deformable DETR（Two-Stage）

#### 6.2.1 动机

标准的 object queries 是**完全随机初始化的可学习 embedding**，没有任何图像内容信息。两阶段变体用 Encoder 输出为 decoder 提供**内容感知的初始化**。

#### 6.2.2 第一阶段：Region Proposal Generation

```
第一阶段：Encoder → Region Proposals

  Encoder Memory [B, ΣHlWl, 256]  (所有像素的特征)
       │
       ├──▶ enc_output = LayerNorm(Linear(memory))  → [B, ΣHlWl, 256]
       │
       ├──▶ class_score = class_embed(enc_output)    → [B, ΣHlWl, N+1]
       │         │
       │         └──▶ top-300 按 objectness score 选出
       │
       └──▶ bbox_offset = bbox_embed(enc_output)     → [B, ΣHlWl, 4]
                 │
                 └──▶ proposal_boxes = grid_coords + bbox_offset
```

这个过程类似于传统检测器中的 RPN（Region Proposal Network），但完全基于 Transformer：

```python
# gen_encoder_output_proposals 的核心逻辑:
def gen_encoder_output_proposals(memory, memory_padding_mask, spatial_shapes):
    # 1. 为每个特征图上的每个像素生成默认 anchor（中心为该像素位置，宽高随层变化）
    for lvl, (H_, W_) in enumerate(spatial_shapes):
        grid_y, grid_x = torch.meshgrid(...)
        grid = (grid + 0.5) / scale              # 归一化中心点
        wh = torch.ones_like(grid) * 0.05 * (2.0 ** lvl)  # 宽高随层指数增大
        proposal = torch.cat((grid, wh), -1)     # [cx, cy, w, h]

    # 2. 过滤无效 proposal（超出图像范围）
    output_proposals_valid = ((proposals > 0.01) & (proposals < 0.99)).all(-1)
    output_proposals = log(proposals / (1 - proposals))  # → logit 空间
    output_proposals[invalid] = -inf

    # 3. 编码器输出 + proposal → decoder 初始 query
    return output_memory, output_proposals
```

#### 6.2.3 第二阶段：Decoder 精调

```
第二阶段：Decoder 精调

  从第一阶段选出的 top-300 proposals:
       │
       ├──▶ topk_coords → sigmoid → reference_points (decoder 初始参考点)
       │
       ├──▶ topk_coords → pos_embed → concat → query_embed + tgt
       │                                         (内容感知初始化！)
       │
       └──▶ DeformableDecoder(tgt, reference_points, encoder_memory)
                 │
                 ▼
            最终预测 (class + bbox)
```

#### 6.2.4 两阶段 vs 标准模式的 query 来源对比

```
标准模式:                          两阶段模式:
─────────────────────────         ─────────────────────────
query_embed = Embedding(300,512)   query_embed = PosEmbed(encoder proposals)
         ↓                                  ↓
  完全与图像无关                     来自 encoder 输出，包含图像内容信息
  训练初期"盲目搜索"                 训练初期就能定位到大致位置

类比:
  · 标准模式 = 给你 300 个"探测器"，     · 两阶段 = 先快速扫描全图，
    你让它们自己学会该看哪里              找到 300 个可疑位置，
                                         再派 300 个"探测器"去精查
```

## 七、损失函数详解

### 7.1 匈牙利匹配（Hungarian Matching）

目标检测的难点之一是**标签分配**：如何将 N 个预测与 M 个真值一一对应？传统方法使用 IoU 阈值 + NMS，DETR 系列使用匈牙利算法做最优二分图匹配。

```
二分图匹配问题：

  预测框 (300个)                    真值框 (M个, M≤300)
  ┌─────┐                          ┌─────┐
  │ pred₀│ ──────── cost₀,₀ ──────▶│ gt₀ │
  │ pred₁│ ──────── cost₁,₀ ──────▶│ gt₁ │
  │ pred₂│ ──────── cost₂,₁ ──────▶│ gt₂ │
  │ ...  │                          │ ... │
  │pred₂₉₉│                         └─────┘
  └─────┘

目标: 找到最小总代价的匹配 σ: {0,...,M-1} → {0,...,299}
其中 σ(i) ≠ σ(j) for i ≠ j (一一对应)

未匹配的预测 → 自动标记为 "no object" (背景类)
```

### 7.2 匹配代价（Matching Cost）

对于预测 i 和真值 j，匹配代价为：

$$\mathcal{C}_{ij} = \lambda_{cls} \cdot \mathcal{C}_{cls}(i,j) + \lambda_{L1} \cdot \mathcal{C}_{L1}(i,j) + \lambda_{giou} \cdot \mathcal{C}_{giou}(i,j)$$

**分类代价（Focal Loss 形式）**：

$$\mathcal{C}_{cls}(i,j) = -\alpha \cdot (1-p_{ij})^\gamma \cdot \log(p_{ij}) - (1-\alpha) \cdot p_{ij}^\gamma \cdot \log(1-p_{ij})$$

其中 \(p_{ij}\) 是预测 i 属于真值类别 j 的概率。

与标准交叉熵的区别：Focal Loss 通过 \((1-p)^\gamma\) 因子降低易分类样本的权重，使模型更关注难分类样本。

**回归代价**：

$$\mathcal{C}_{L1}(i,j) = \|b_i - b_j\|_1$$
$$\mathcal{C}_{giou}(i,j) = -\text{GIoU}(b_i, b_j)$$

算法实现（`scipy.optimize.linear_sum_assignment`）：

```python
for b in range(batch_size):
    cost_matrix[b] = λ_cls*C_cls + λ_L1*C_L1 + λ_giou*C_giou
    indices[b] = linear_sum_assignment(cost_matrix[b])
```

### 7.3 训练损失

匹配完成后，对匹配上的预测对计算最终损失：

$$\mathcal{L} = \lambda_{cls} \cdot \mathcal{L}_{cls} + \lambda_{L1} \cdot \mathcal{L}_{L1} + \lambda_{giou} \cdot \mathcal{L}_{giou}$$

**分类损失（Focal Loss）**：
- 匹配上的预测：计算其属于真值类别的 Focal Loss
- 未匹配的预测：计算其属于"背景"类的 Focal Loss

**回归损失**：
- L1 Loss：直接回归 (cx, cy, w, h)
- GIoU Loss：尺度不变的 IoU 扩展损失

$$\text{GIoU} = \text{IoU} - \frac{|C \setminus (A \cup B)|}{|C|}$$

其中 C 是包含 A 和 B 的最小闭包框。

### 7.4 辅助损失（Auxiliary Loss）

每个 decoder 层的输出都计算损失，帮助梯度流动，加速收敛：

```python
# 6 层 decoder → 6 个损失，最后一层为主损失
out['aux_outputs'] = [
    {'pred_logits': class_i, 'pred_boxes': bbox_i}
    for i in range(num_decoder_layers - 1)  # 前 5 层为辅助
]
# 最后一层 (outputs_class[-1], outputs_coord[-1]) 为主损失
```

## 八、训练细节与技巧

### 8.1 分层学习率

不同模块使用不同学习率，因为 backbone 预训练权重已较好，不需大幅调整：

| 参数组 | 学习率倍数 | 基准 lr | 有效 lr |
|--------|-----------|---------|---------|
| backbone 参数 | ×0.1 | 2e-4 | 2e-5 |
| sampling_offsets + reference_points | ×0.1 | 2e-4 | 2e-5 |
| 其他 Transformer 参数 | ×1.0 | 2e-4 | 2e-4 |

### 8.2 分类头初始化

使用偏置初始化技巧来缓解类别不平衡：

```python
prior_prob = 0.01  # 假设每个 query 有 1% 概率匹配到物体
bias_value = -log((1 - prior_prob) / prior_prob)
# = -log(99) ≈ -4.595
self.class_embed.bias.data = torch.ones(num_classes) * bias_value
```

这意味着初始时，分类头输出 sigmoid 后约为 0.01，与先验匹配概率一致，避免训练初期大量输出被错误分类。

## 十、总结与对比

### 10.1 DETR vs Deformable DETR

```
┌────────────────────────────────────────────────────────────────────┐
│                    DETR vs Deformable DETR                          │
├──────────────────┬──────────────────────┬──────────────────────────┤
│      维度         │        DETR          │    Deformable DETR       │
├──────────────────┼──────────────────────┼──────────────────────────┤
│ 注意力机制        │ 全局注意力           │ 稀疏可变形注意力          │
│ Encoder 复杂度    │ O((HW)²·C)          │ O(HW·K·C), K=4           │
│ Decoder 交叉注意力 │ O(N_q·HW·C)         │ O(N_q·L·K·C)            │
│ 多尺度特征        │ 不支持（仅 C5）      │ 支持 L=4 层              │
│ 训练收敛          │ 500 epoch            │ 50 epoch (10× faster)    │
│ 小目标 (AP_S)     │ 20.5                 │ 27.1 (+32%)              │
│ 参数量            │ 41M                  │ 40M                      │
│ FLOPs             │ 86G                  │ 173G                     │
│ 推理速度 (FPS)    │ 27                   │ 15                       │
│ 端到端            │ ✓                    │ ✓                        │
│ 无需 NMS          │ ✓                    │ ✓                        │
│ 无需 Anchor       │ ✓                    │ ✓                        │
├──────────────────┴──────────────────────┴──────────────────────────┤
│                                                                     │
│  核心哲学:                                                          │
│  DETR: "Attention is All You Need" — 让模型自己学会关注哪里         │
│  Deformable DETR: "只看关键位置" — 显式引导模型做稀疏注意力          │
│                                                                     │
└────────────────────────────────────────────────────────────────────┘
```

### 10.2 核心创新总结

1. **可变形注意力**：将"全图搜索"变为"参考点邻域搜索"，复杂度从 O(HW) 降至 O(K)
2. **多尺度融合**：得益于低复杂度，可以同时使用 4 层特征图，大幅提升小目标性能
3. **迭代精调**：decoder 层间级联，形成由粗到精的预测流水线
4. **两阶段初始化**：encoder 生成 content-aware 的 query 初始化，进一步加速收敛

### 10.3 后续影响

Deformable DETR 的思想深刻影响了后续工作：
- **Deformable DETR** (2020) → 稀疏注意力 + 多尺度
- **Sparse R-CNN** (2021) → 稀疏 proposal + 动态交互
- **Deformable DETR v2** → 更强的 backbone + 改进训练策略
- **DINO** (2023) → 对比去噪训练 + 混合 query 选择
- **Mask DINO** → 统一检测与分割
- **Grounding DINO** → 开放词汇检测

这一系列工作共同形成了"DETR-like"目标检测范式，成为与 YOLO 系列并驾齐驱的端到端检测主流路线。
