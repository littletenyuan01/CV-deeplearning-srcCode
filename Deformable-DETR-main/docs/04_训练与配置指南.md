# 训练与配置指南

---

## 一、环境配置

### 1.1 系统要求

- Linux 操作系统
- CUDA >= 9.2
- GCC >= 5.4
- Python >= 3.7

### 1.2 安装步骤

```bash
# 1. 创建 conda 环境
conda create -n deformable_detr python=3.7 pip
conda activate deformable_detr

# 2. 安装 PyTorch（根据 CUDA 版本选择）
conda install pytorch=1.5.1 torchvision=0.6.1 cudatoolkit=9.2 -c pytorch

# 3. 安装其他依赖
pip install -r requirements.txt
```

### 1.3 编译 CUDA 算子

```bash
cd ./models/ops
sh ./make.sh

# 单元测试（全部通过才算成功）
python test.py
```

## 二、模型变体及配置

本项目提供 5 种配置，复杂度递增：

| 配置 | 文件 | 说明 | AP (50 epoch) |
|------|------|------|:---:|
| 单尺度 | `r50_deformable_detr_single_scale.sh` | 仅使用 C5 特征图 | 39.4 |
| 单尺度+DC5 | `r50_deformable_detr_single_scale_dc5.sh` | C5 使用空洞卷积 | 41.5 |
| **标准多尺度** | `r50_deformable_detr.sh` | 4 层多尺度特征 | **44.5** |
| +迭代精调 | `r50_deformable_detr_plus_iterative_bbox_refinement.sh` | 每层 decoder 迭代精调 bbox | 46.2 |
| ++两阶段 | `r50_deformable_detr_plus_iterative_bbox_refinement_plus_plus_two_stage.sh` | encoder 生成 proposals | **46.9** |

### 2.1 配置文件示例

```bash
# configs/r50_deformable_detr.sh
EXP_DIR=exps/r50_deformable_detr
python -u main.py \
    --output_dir ${EXP_DIR} \
    ${PY_ARGS}
```

所有模型参数使用默认值，可通过命令行覆盖。关键默认值：

```python
# Transformer
--hidden_dim 256        # 隐层维度
--nheads 8              # 注意力头数
--enc_layers 6          # Encoder 层数
--dec_layers 6          # Decoder 层数
--dim_feedforward 1024  # FFN 维度
--dropout 0.1

# 多尺度
--num_feature_levels 4  # 特征层级数
--dec_n_points 4        # Decoder 采样点数
--enc_n_points 4        # Encoder 采样点数

# 训练
--epochs 50             # 训练轮数
--lr 2e-4               # Transformer 学习率
--lr_backbone 2e-5      # Backbone 学习率
--batch_size 2          # 每 GPU batch size
--lr_drop 40            # 第 40 epoch 降低学习率
```

## 五、学习率策略

### 5.1 分层学习率

| 参数组 | 学习率倍数 | 说明 |
|--------|-----------|------|
| `backbone` | 0.1× | backbone 参数不频繁更新 |
| `reference_points` + `sampling_offsets` | 0.1× | 采样相关参数需要更稳定 |
| 其他（Transformer） | 1.0× | 正常学习率 |

```python
# main.py 中的参数分组
param_dicts = [
    {"params": [p for n, p in model_without_ddp.named_parameters()
                if "backbone" not in n and p.requires_grad]},
    {"params": [p for n, p in model_without_ddp.named_parameters()
                if "backbone" in n and p.requires_grad],
     "lr": args.lr_backbone},  # 2e-5
]
```

### 5.2 学习率衰减

- 默认在第 **40 epoch** 衰减（总 50 epoch）
- 衰减因子：0.1
- 使用 StepLR 调度器

## 七、训练技巧与注意事项

### 7.1 正确性

- **总 batch size 应为 32**：如 8 卡 × 每卡 4 samples
- 如修改 batch size，可能需要调整学习率（线性缩放规则）
- CUDA 算子编译失败时，检查 CUDA 版本和 GCC 版本兼容性

### 7.2 性能优化

- 使用 `data_prefetcher` 实现 CPU-GPU 数据传输与计算流水线化
- `im2col_step=64` 控制 CUDA kernel 的并行粒度
- Backbone 使用 FrozenBatchNorm2d 减少显存占用

### 7.3 常见问题

| 问题 | 解决方案 |
|------|----------|
| CUDA out of memory | 减小 `batch_size` 或使用 gradient accumulation |
| NaN loss | 检查学习率是否过大，尝试 warmup |
| 编译失败 | 确认 CUDA_HOME 环境变量正确，GCC 版本 ≥ 5.4 |
| 训练不收敛 | 检查数据集路径、标注格式是否正确 |
